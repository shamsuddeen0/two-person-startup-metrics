# Two-Person Startup Metrics

This repository contains a simple, actionable metrics spreadsheet template and guidance for two-person startups.

Purpose
- Track only the metrics you can act on.
- Keep reporting lightweight and update weekly.
- Tie each metric to an owner and a decision.

Files
- metrics-template.csv — core metrics, definitions, calculation methods, frequency, and ownership.

How to use
1. Open metrics-template.csv in Google Sheets, Excel, or your preferred spreadsheet app.
2. Fill in Data Source and Current Value each week (recommended: update every Friday).
3. Use the "Target" column to set short-term goals (weekly/monthly).
4. Keep the sheet focused: if a metric is not actionable, remove it.

Weekly process (example)
- Every Friday: update Current Value for each metric and add a short note for major changes.
- Weekly sync (30–60 minutes): review key metric changes, decide 1–2 experiments or actions for next week.

Recommended owners for a two-person startup
- Founder / Product (Person A) — owns product, discovery, activation, retention metrics.
- CTO / Engineering (Person B) — owns stability, delivery, time-to-fix, technical health metrics.
